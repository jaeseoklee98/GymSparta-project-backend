# 🏋️ GymSparta Project

> **헬스장과 고객을 연결하는 위치 기반 B2C 서비스**  
> 간편한 헬스장 검색부터 이용권 구매, 리뷰까지 한 번에!

---

### 📅 프로젝트 기간

2024.07.17 ~ 2024.08.21

---

### 🔍 주요 기능

- **회원 기능**: 회원가입, 로그인, 로그아웃  
- **매장 관리**: 점주 전용 매장 등록/수정/삭제  
- **알림 기능**: 결제 완료, 만료 임박, 공지 등 실시간 알림 제공  
- **리뷰 시스템**: 이용한 매장과 PT에 대한 리뷰/평점 작성 가능  
- **위치 기반 검색**: Google Maps API를 활용한 주변 매장 탐색 기능
